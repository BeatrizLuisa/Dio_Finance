# Dio_Finance
Simulador de Investimentos, para planejamento financeiro.

O simulador Dio Finance, foi criado para ajudar investidores a responder perguntas como:
- Quanto investir?
- Por quanto tempo?
- A que taxa?
- Quanto de retorno mensal?
- Quanto de patrimonio acumulado?

De maneira intuitiva e dinâmica. 

### Atenção!
Para uso assertivo do simulador, os campos pintados em cinza **NÃO DEVEM SER ALTERADOS!**
